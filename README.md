# Cisco Networking Labs 🌐

This repository contains my practical Cisco networking labs created using **Cisco Packet Tracer**.

These labs demonstrate my hands-on practice with VLANs, routing protocols, DHCP, ACLs, and inter-VLAN communication.

## 🛠️ Tools & Technologies

- Cisco Packet Tracer
- Cisco IOS
- IPv4 Networking
- VLAN
- Inter-VLAN Routing
- Static Routing
- RIP
- OSPF
- EIGRP
- DHCP
- Access Control List (ACL)

## 📂 Labs

| Lab | Topics |
|---|---|
| `VLAN.pkt` | VLAN configuration and segmentation |
| `INTER VLAN.pkt` | Inter-VLAN routing |
| `STATIC.pkt` | Static routing |
| `RIP.pkt` | RIP dynamic routing |
| `OSPF.pkt` | OSPF dynamic routing |
| `EIGRP.pkt` | EIGRP routing |
| `DHCP.pkt` | DHCP configuration |
| `ACL.pkt` | Network traffic filtering using ACL |

## 🎯 Learning Objectives

Through these labs, I practiced:

- Configuring Cisco routers and switches
- Creating and managing VLANs
- Configuring inter-VLAN communication
- Implementing static and dynamic routing
- Working with OSPF, RIP and EIGRP
- Configuring DHCP services
- Applying basic network security using ACLs
- Verifying network connectivity and troubleshooting configuration issues
